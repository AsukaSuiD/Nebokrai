# Сообщения о безопасности

Nebokrai находится в разработке. Поддерживаемых стабильных релизов и обещанного срока исправления сейчас нет; предмет разбора — текущая основная реализация и отслеживаемые инструменты. Локальные стенды не являются готовым защищённым публичным сервисом. Границы клиентских и runtime-проверок находятся в [состоянии проекта](docs/status/audit.md).

Не публикуйте секреты, сведения об учётных записях, эксплуатационные payload, оригинальные бинарники, дампы БД, памяти или сетевые захваты в публичных issue/PR. Для первоначального сообщения достаточно commit, затронутого компонента, класса воздействия и обезличенных шагов воспроизведения на собственной среде.

Используйте кнопку **Report a vulnerability** на вкладке Security репозитория, если владелец включил private vulnerability reporting. Наличие этого канала пока не подтверждено. Если кнопки нет и вы не располагаете ранее согласованным личным каналом владельца, запросите приватный контакт без описания уязвимости и без вложений. Не отправляйте чувствительные сведения через обычный issue.

Перед публикацией владелец должен включить и проверить приватный канал либо указать здесь действующий адрес для таких сообщений. Эта настройка не выполняется автоматически добавлением файла.

При утечке credentials сначала отзовите или замените их у соответствующего поставщика. Удаление строки из Git не отзывает credential; очистка истории не удаляет копии у других лиц. Разбор публикационных рисков и оставшиеся решения — в готовности к публикации (локальный материал владельца).
