# Состояние проекта / Current status

**English summary.** Six Rust services have compiled and started together on Linux. The legacy client reached character selection; subsequent observations include character loading and Game registration. A stable playable session has not been demonstrated. Later fixes still need the corresponding scenarios repeated. This page summarizes the [detailed audit](../status/audit.md), which remains the authoritative record.

Сводка основана на наблюдениях, зафиксированных к 21 сентября 2026 года. Службы запускались на описанных в аудите сборках; это не подтверждение повторного запуска после каждого последующего изменения.

## Ближайший неподтверждённый этап

Главный пробел — нет повторного клиентского сценария после последних исправлений входного снимка и движения. Ранее клиент падал при разборе снимка; исправления и перезапуск служб ещё не доказывают устранение отказа в клиенте. Нужно зафиксировать результат входа до управляемого персонажа и движение на конкретной сборке. Это ближайшая проверка, а не утверждение о единственной оставшейся ошибке.

Наличие игрового цикла и обработчиков подтверждено кодом и запуском процесса; устойчивое взаимодействие игрока с этим циклом — нет. Детали: [загрузка](../status/audit.md#проверка-всей-последовательности-загрузки), [статическая реконструкция движения](../status/audit.md#статическая-реконструкция-движения-21-сентября). Остальные строки таблицы также не получают runtime-подтверждения от статического анализа.
