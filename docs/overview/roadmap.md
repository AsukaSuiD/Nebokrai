# Направления дальнейшей работы / Roadmap

Приоритеты работы определяются существующим кодом и незавершёнными игровыми путями. Архитектурное распределение принято в [карте компонентов Realm и Zone](../architecture/realm-and-zone.md): она задаёт владельцев, операции и причины разделения. Это основание для рефакторинга, а не описание уже выполненного перехода. Наблюдения клиента и результаты запусков остаются в [аудите](../status/audit.md).

1. **Связать ресурсы, загрузку игрока и первое неработающее действие.** Проследить определения до потребителя, затем поиск и исполнение навыка/удара либо взаимодействие с NPC и заданием. Различить отсутствие данных, неполную инициализацию и отказ самой операции. Рефакторить затронутый путь по принятой карте; не считать успешный вход достаточной проверкой игрока.
2. **Разделять существующие компоненты вместе с устранением их связности.** Выделять владельцев внутри нынешних Game/World, отделять общие механизмы от игровых решений, собирать Realm/Zone из этих частей. Для каждого переноса фиксировать обращения, данные и отказные ветви; переименование файлов само по себе не завершает задачу.
3. **Разбирать нагрузку по измеряемой работе.** Сравнивать CPU, память и длительность стадий на сопоставимых сборках и сценариях, используя существующие измерения. Проверять ненужные обходы, копии и повторную подготовку данных; не приписывать эффект языку или числу бинарников без сравнения.
4. **Доводить сквозные сценарии.** Изменение состояния → выход → сохранение → повторный вход, затем переход региона; предметы, бой, задания, аукцион и платежи — с их частичными эффектами и отказами. Подробности уточняются на страницах соответствующих подсистем по мере работы, без второй параллельной спецификации.

Кандидат первого содержательного релиза должен включать утверждённую лицензию, проверенную границу поставки, воспроизводимую сборку, точный список подтверждённых сценариев и известных ограничений. Номер, дата и обещание playable-сервера пока не устанавливаются. Эти направления не создают релизов, issue или обязательств участников.
