# Направления дальнейшей работы / Roadmap

**English summary.** These are evidence-driven priorities, not scheduled releases or claims of assigned work. The next useful milestone is a reproducible client session with documented build identities and explicit gaps. Later milestones depend on that result.

1. **Повторить путь входа после исправлений.** Зафиксировать состав служб, идентификатор клиента, подготовку данных и этап отказа либо успешного входа. Результат должен различать список, загрузку, регистрацию и фактически управляемого персонажа.
2. **Подтвердить жизненный цикл.** Изменение состояния, выход, сохранение и повторный вход; затем переход региона. Описывать также ошибки и частичные эффекты.
3. **Проверять подсистемы конкретными сценариями.** Движение, бой, предметы и навыки; отдельно аукцион и платежи. Для каждого сценария нужна граница утверждения, а не общее «работает».
4. **Расширять воспроизводимость документации.** Краткие английские summaries ключевых входных страниц, ссылки на основную русскую спецификацию, дополнительные case studies реальных исправлений. Дублировать весь справочник не требуется.

Кандидат первого содержательного релиза должен включать утверждённую лицензию, проверенную границу поставки, воспроизводимую сборку, точный список подтверждённых сценариев и известных ограничений. Номер, дата и обещание playable-сервера пока не устанавливаются. Эти направления не создают релизов, issue или обязательств участников.
