# Техническая документация Nebokrai

Этот раздел — техническая спецификация текущего понимания «Поднебесья» и решений Nebokrai. Он фиксирует поведение, владельцев состояния, wire-контракты, порядок действий и формул, ошибки, источники и неизвестное. Каталог файлов — лишь навигация. Читайте тематический документ перед повторным анализом кода и EXE/PDB; возвращайтесь к первичным материалам, когда документ прямо отмечает открытый вопрос.

## Как поддерживать раздел

Меняйте тематический документ вместе с изменением соответствующего поведения или новым подтверждением. Для каждой существенной системы указывайте назначение, владельца, состояние, lifecycle, контракты, инварианты, порядок действий и формул, ошибки, отличие от технической реализации оригинала, доказательство, ссылку на код и неизвестное. Статус `VERIFIED` относится к конкретному факту оригинала; сборка и проверка Nebokrai с клиентом отмечаются отдельно. Не заменяйте пробелы догадкой.

Точный вариант EXE/PDB, RVA и локальную особенность owner-а сохраняйте также в верхнем комментарии его файла. Тематическая страница собирает эти сведения в системный контракт, чтобы следующему разработчику не пришлось повторять уже проделанный реверс.
