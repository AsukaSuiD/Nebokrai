# Материалы для реконструкции

Для обычной разработки достаточно [документации](../README.md) и текущего кода. Материалы ниже нужны, когда необходимо установить конкретное поведение оригинала: поле сообщения, формулу, порядок вызовов или результат ошибки.

| Локальный путь | Содержимое | Когда использовать |
| --- | --- | --- |
| `original/server/Miracle_server/` | Оригинальный Windows-комплект: EXE/PDB шести серверов, ресурсы и настройки. | Сопоставить символ с машинным кодом, проверить структуру данных или поведение конкретной сборки. Полноценных C/C++-исходников сервера в комплекте не найдено. |
| `.exe/` | Локальные оригинальные бинарники для анализа. | Найти нужный вариант EXE/PDB; версию проверять по имени, символам и хешу из комментария исследуемого файла. |
| `ghidra/`, `reports/` | Результаты анализа и рабочие отчёты. | Найти уже разобранную функцию или зафиксированное наблюдение. |
| `related/Luvinia/` | Код другой игры на том же движке. | Проверить гипотезу об общем механизме; конкретное правило «Поднебесья» всё равно требует своего основания. |

Эти пути описывают необязательные локальные материалы, а не содержимое клона или ссылки для скачивания. Эти каталоги остаются локальными и исключены из Git. Оригинальный комплект хранится без правок; изменяемые данные стенда находятся в `runtime/`.

[server/cpp/](../../server/cpp/) — отдельная реализация в репозитории. К ней можно обратиться по конкретному вопросу, но основная разработка не требует предварительно сверять с ней каждое изменение.

Для установленного факта сохраняйте точную привязку к варианту EXE/PDB, символу или адресу в комментарии исходного файла. В тематической документации объясняйте само поведение и ставьте ссылку на эту привязку. [Правила реконструкции](evidence-and-contracts.md) описывают, как обозначать неизвестное.

Граница локальных материалов — правило организации проекта, а не заключение о праве распространения всего исторического корпуса. Обнаруженные в отслеживаемых файлах RAW-остатки и порядок решения перед публикацией отмечены в готовности к публикации (локальный материал владельца). Идентификаторы сборок, адреса и статусы свидетельств сохраняются.
