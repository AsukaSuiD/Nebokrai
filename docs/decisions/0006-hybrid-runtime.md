# ADR-0006: гибридный локальный стенд

Принято для текущего локального стенда.

## Решение и причина

[deploy/hybrid](../../deploy/hybrid/) запускает пять Rust-служб — Auth, Login, Billing, World и Misc — вместе с оригинальным Windows GameServer через Wine. Такой состав позволяет работать над соседними службами и их обменом, используя доступный оригинальный игровой процесс.

Rust GameServer остаётся отдельной частью разработки. Проверка гибридного состава относится именно к участвующим в нём процессам.

## Последствия

[Rust Dockerfile](../../deploy/hybrid/Dockerfile.rust) собирает все шесть бинарников, но копирует в конечный образ пять. Поэтому ошибка компиляции Rust GameServer может остановить сборку и этого образа. Проверки портов в Compose показывают доступность служб; игровые сценарии проверяются отдельно.

Конфиги, ресурсы, EXE и backup БД находятся в локальном `runtime/`. SQL login `Miracle` сохраняет имя, поскольку его используют настройки и базы; смена имени потребует согласованного изменения обеих сторон.

В результатах проверки указывают commit, версию клиента и состав стенда. Замена Wine-процесса на Rust GameServer требует сборки, запуска и клиентских сценариев этого бинарника. Подготовка и ограничения описаны в [локальном стенде](../operations/hybrid-runtime.md).
