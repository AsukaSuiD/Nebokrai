# ADR-0006: гибридный локальный стенд

Принято для гибридного локального стенда; дополнено отдельным режимом всех Rust-служб.

## Решение и причина

[deploy/hybrid](../../deploy/hybrid/) запускает пять Rust-служб — Auth, Login, Billing, World и Misc — вместе с оригинальным Windows GameServer через Wine. Такой состав позволяет работать над соседними службами и их обменом, используя доступный оригинальный игровой процесс.

Для работы над Rust GameServer добавлен [совместный Rust-режим](../operations/rust-runtime.md): Compose-дополнение заменяет игровой процесс и подключает шесть dev-бинарников из общего ограниченного кэша. Базы, runtime и сеть переиспользуются; отдельный образ при каждой правке не нужен. Проверка каждого состава относится именно к участвующим в нём процессам.

## Последствия

[Rust Dockerfile](../../deploy/hybrid/Dockerfile.rust) собирает и копирует в конечный образ все шесть бинарников. Поэтому ошибка компиляции Rust GameServer может остановить сборку и гибридного образа. Базовые healthcheck ищут запись с номером порта без проверки состояния `LISTEN`; клиентский порт Login не проверяется. Rust-дополнение отдельно проверяет `LISTEN` Game на 2347. Эти признаки не подтверждают полноценную готовность службы. Точные условия разобраны в [диагностике](../operations/diagnostics.md).

Конфиги, ресурсы, EXE и backup БД находятся в локальном `runtime/`. SQL login `Miracle` сохраняет имя, поскольку его используют настройки и базы; смена имени потребует согласованного изменения обеих сторон.

В результатах проверки указывают commit, версию клиента и состав стенда. Замена Wine-процесса на Rust GameServer требует сборки, запуска и клиентских сценариев этого бинарника. Подготовка и ограничения описаны в [локальном стенде](../operations/hybrid-runtime.md).
