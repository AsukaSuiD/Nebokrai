# ADR-0011: отказ генерации GUID не создаёт предмет

Принято 22 сентября 2026 года при разборе потребителей Shared GUID.

Linux-адаптер `CGuid::create` возвращает ошибку системного источника случайности. Game подставлял вместо неё `GUID_INVALID`: разделение стопок затем проверяло этот ноль, но фабрика новых предметов и сценарный аукцион могли принять его как идентичность результата. Если просто пропустить неудачный предмет в наборе, магазин может выдать меньше запрошенного, сохранив полную цену.

Game переводит отказ в отсутствие результата с записью причины в журнал. Фабрика не возвращает новый экземпляр без ненулевого GUID; пакетное создание при отказе отбрасывает весь локально подготовленный набор. Временный расчёт свойств использует отдельную операцию без создания идентичности. У разделения стопки сохраняется существующая ветка отказа контейнера; сценарный аукцион прекращает проход до замены текущего узла неудачным результатом.

Это решение для ошибки собственной Rust/Linux-инфраструктуры, а не утверждение о реакции оригинального `CoCreateGuid`. Успешный путь сохраняет игровые броски и их порядок, форматы и точки предметных изменений. На отказе уже выполненные броски не откатываются. Набор фабрики ещё не опубликован, но уже совершённые внешние действия вызывающей операции автоматически не компенсируются; общей транзакции над торговлей, Billing и инвентарём это решение не вводит.
