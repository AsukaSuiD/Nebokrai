# ADR-0004: локальные сравнительные источники вне Git

Статус решения: принято. Область: организация исходных материалов.

## Контекст

Оригинальные EXE/PDB, прежние попытки и Luvinia выполняют разные роли. Они велики, содержат runtime-конфигурации и сборочные продукты, а часть одинаковых файлов отличается между снимками. Если смешать их с `server/rust`, можно принять старый код или игру-родственника за доказательство актуального поведения.

## Решение

Четыре снимка серверной линии лежат в локальном `server/references/`, Luvinia — в локальном `related/`. Оба пути исключены из Git. Внутренние файлы сохраняются без правок, сравнение всегда называет вариант и конкретное свидетельство. В Git попадают не бинарники и гигабайтные копии, а полученный контракт и источник его проверки в тематической документации. [Карта источников](../reconstruction/sources.md) фиксирует различия.

## Последствия

Другой разработчик может читать спецификацию без локальных снимков, но для перепроверки спорного RVA ему потребуются соответствующие EXE/PDB. Снимки нельзя автоматически дедуплицировать: совпадающие ресурсы соседствуют с разными конфигурациями и состояниями. Luvinia пригодна для гипотезы об общем движке, но не повышает уровень знания игрового правила Nebokrai до `VERIFIED`.
