# ADR-0005: сохранять границу владельцев World и Game

Статус решения: принято. Область: состояние игрока, межсерверные сообщения и сохранение.

## Контекст

Исходная серверная линия разделяет долговременное мировое состояние и живую симуляцию региона. При входе Game запрашивает игрока у World, получает результат загрузки, а затем обслуживает команды и события игры. World владеет мировым снимком и операциями БД. Если убрать эту границу как «лишний transport», появится несколько мест, которые одновременно считают себя источником истины для игрока, либо изменится момент SQL-записи относительно сетевых ответов.

## Решение

Nebokrai сохраняет отдельных владельцев WorldServer и GameServer. Game меняет живое состояние региона; World загружает и сохраняет мировой снимок. Их связь пока остаётся сообщениями исходного межсерверного формата. Выделенный socket как конкретный способ доставки не объявляется вечным игровым правилом, но адресация игрока, содержимое `GameSave`, очередность `0x5FB01 → 0x7F901 → 0xBF401`, самостоятельные ошибки и порядок уже совершённых side effects являются контрактом, который нельзя убрать простой заменой сетевого вызова локальным.

Применять другую топологию можно только после явного сопоставления этих гарантий и дифференциальной проверки. До этого изменение владельца БД или выполнение Game-логики в World запрещено архитектурной границей, даже если локальный вызов кажется быстрее.

## Основания и предел

[Модель владения](../architecture/state-ownership.md) показывает достигнутый переход, [спецификация входа Game](../protocol/game-login.md) — поля и порядок сообщений, а [модель БД](../architecture/database.md) — сохранение. Верхние комментарии [`World CGame`](../../server/rust/src/worldserver/worldserver/game.rs), [`Game CGame`](../../server/rust/src/gameserver/gameserver/game.rs) и [`savedb.rs`](../../server/rust/src/worldserver/worldserver/savedb.rs) называют точные EXE/PDB. Разделение исходных владельцев и достигнутый порядок `VERIFIED`; полная эквивалентность современного асинхронного runtime и политика глобального порядка между разными TCP-соединениями `PARTIAL`/`UNKNOWN`. Этот ADR фиксирует решение Nebokrai, не доказывает эти неизвестные факты.
