# Nebokrai

`miracle_engine` — рабочее пространство проекта `Nebokrai` и локальных исходных материалов, используемых при его реконструкции.

## Проекты

- [`Nebokrai`](Nebokrai/README.md) — основной рабочий проект.

## Архив

`archive/` — локальный read-only источник оригинальных материалов, предыдущих попыток и доноров. Архив не является рабочим проектом и не должен определять структуру нового кода.
