# Nebokrai

Nebokrai — реконструкция серверной части «Поднебесья» на основе оригинальных EXE/PDB, данных, наблюдений и уже выполненного анализа. Цель — поддерживаемая реализация с сохранением подтверждённой игровой и сетевой семантики. Наличие кода, компиляция и работа с исходным клиентом оцениваются отдельно; текущая готовность указана в [аудите](docs/status/audit.md).

## С чего начать

[Техническая документация](docs/README.md) описывает модель системы: роли процессов, владение состоянием, протоколы, игровые алгоритмы, БД, свидетельства и принятые инженерные решения. Если нужного контракта там нет, проверьте статус знания и точечный источник в owner-файле или первичных материалах. Документы описывают текущую систему, а историю изменений хранит Git.

## Дерево проекта

| Путь | Роль |
| --- | --- |
| [`server/rust/`](server/rust/) | Активная Rust-реконструкция шести серверных процессов. `src/bin/` содержит входы, `src/process/` — запуск, остальные модули сгруппированы по владельцам исходных серверов. |
| [`server/cpp/`](server/cpp/) | Отдельный C++-проход и дополнительный технический источник. Его полнота и соответствие оригиналу не предполагаются автоматически. |
| [`deploy/`](deploy/) | Конфигурация локального гибридного стенда и сборочных образов. Состав и ограничения описаны в [операционном разделе](docs/operations/hybrid-runtime.md). |
| [`docs/`](docs/) | Спецификация системы, ADR, реконструкция, эксплуатация и честный статус проверки. |
| `server/references/` | Локальные неизменяемые снимки оригинального Windows runtime и трёх прежних реализаций; исключены из Git. |
| `related/Luvinia/` | Локальный материал родственной игры на том же движке; отдельный сравнительный источник, исключённый из Git. |
| `runtime/`, `.exe/`, `ghidra/`, `reports/` | Локальные данные стенда, оригинальные бинарники, результаты анализа и рабочие отчёты; исключены из Git. |

[Роли и происхождение источников](docs/reconstruction/sources.md) объясняют, какие сведения допустимо брать из каждого локального снимка. Оригинальный `Miracle_server` содержит рабочие Windows EXE/PDB и данные, но не полноценные исходники сервера. Luvinia — другая игра, её поведение не является доказательством поведения Nebokrai.

## Границы реконструкции

Подтверждённые протоколы, структуры, порядок побочных эффектов, lifecycle и игровые формулы составляют совместимый контракт. Старые реализации транспортного цикла, Win32 ADO/COM или контейнеров сами по себе таким контрактом не являются. Активный Rust использует современные библиотеки для инфраструктуры; каждую замену проверяют на сохранение значимой семантики и фиксируют в [решениях](docs/decisions/README.md).

Исходная модель данных опирается на MSSQL и хранимые процедуры. Tiberius заменяет способ подключения, но не объявляет миграцию схемы. Подробнее: [границы БД](docs/architecture/database.md).
