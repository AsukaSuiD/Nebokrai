# Miracle Engine

Текущее направление — восстановление старой игры в нормальный исходный проект.
Сначала серверные бинарники с PDB преобразуются в проверяемый читаемый C++, затем
результаты собираются в связанные классы, файлы и собираемый проект.

Папка re-agent содержит локальную исправленную версию конвейера автоматического
реверса. В Nebokrai настроены очереди семи серверных компонентов с проверенными
PDB; клиент пока исключён. archive остаётся локальным read-only источником
оригинальных материалов. Направление с Unreal Engine остановлено.
