# Nebokrai

Nebokrai — сервер «Поднебесья», восстанавливаемый на Rust для Linux. Мы сохраняем игровые правила и совместимость с исходным клиентом, а платформенную часть строим на современных библиотеках.

Начать работу: [руководство разработчика](docs/development.md). Все темы собраны в [документации](docs/README.md).

## Устройство проекта

| Каталог | Что здесь |
| --- | --- |
| [server/rust/](server/rust/) | Основной сервер: Auth, Login, World, Game, Billing и Misc. |
| [server/cpp/](server/cpp/) | Отдельная C++-реализация со своей сборкой; в основной Rust-сервер не входит. |
| [deploy/](deploy/) | Образы и конфигурация локального стенда. |
| [docs/](docs/) | Устройство системы, работа с кодом, протокол, игровые механики и причины решений. |

Локальные данные стенда лежат в `runtime/`, оригинальный Windows-комплект — в `original/server/`. Оригинальные бинарники, материалы анализа и код родственной игры остаются вне Git. Подробности — в [карте каталогов](docs/architecture/workspace.md).

## Основные решения

Game ведёт живую симуляцию региона, World загружает и сохраняет персонажей. Tokio обслуживает сеть и задачи; Tiberius подключает сервер к существующей MSSQL-модели. Собственные форматы сообщений и значимый порядок игровых действий сохраняются. Причины и последствия этих решений описаны в [ADR](docs/decisions/README.md).

[Гибридный стенд](docs/operations/hybrid-runtime.md) использует пять Rust-служб и оригинальный GameServer под Wine. Для совместного запуска всех шести Rust-процессов есть [отдельный режим](docs/operations/rust-runtime.md) на тех же данных и сети. Сборочные команды приведены в [руководстве по сборке](docs/operations/build.md), результаты проверок — в [состоянии проекта](docs/status/audit.md). Ознакомление с проектом и правка документации не требуют запуска сборок, тестов или серверов.

## Публикация и участие

Nebokrai — независимая современная реконструкция для сохранения поведения системы и совместимости с legacy-клиентом. Проект не аффилирован с первоначальными разработчиками или издателями игры и не заявляет об их поддержке. Названия и товарные знаки принадлежат соответствующим правообладателям.

Оригинальный клиент, игровые ресурсы, EXE/DLL/PDB, backup БД и частные исследовательские материалы не входят в предполагаемую открытую поставку. В текущем дереве остаются RAW-материалы, требующие решения перед публикацией; описание границы поставки не означает, что вся история Git уже прошла правовую очистку. Подробности — готовность к публикации (локальный материал владельца).

Лицензия пока не выбрана: подготовка не предоставляет открытой лицензии на код. Сравнение вариантов (локальный материал владельца) объясняет вопросы коммерческого лицензирования и будущих вкладов. Для участия прочитайте [CONTRIBUTING.md](CONTRIBUTING.md), для сообщений об уязвимостях — [SECURITY.md](SECURITY.md). Подробная техническая документация остаётся преимущественно на русском.
